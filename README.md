#  Proyecto Santana

Plataforma web de gestión y difusión de proyectos legislativos. Esta aplicación permite a un concejal publicar sus proyectos y compartirlos fácilmente con la comunidad a través de enlaces directos y códigos QR.

###  Descripción
El objetivo principal es modernizar la forma en que se comunican las iniciativas legislativas. Los ciudadanos pueden navegar, buscar y filtrar los proyectos presentados, visualizando los detalles de manera clara y accesible.

###  Tecnologías Utilizadas
* **Backend:** PHP (Laravel)
* **Base de Datos:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Control de Versiones:** Git / GitHub

###  Funcionalidades Principales

* **Catálogo de Proyectos:** Visualización de proyectos en tarjetas (cards) con imágenes destacadas.
* **Buscador y Filtros:**
    *  Búsqueda por nombre del proyecto.
    *  Filtrado por Categoría y Tipo.
    *  Ordenamiento por Abecedario, Fecha de subida y Categoría.
* **Detalle del Proyecto:** Vista individual con información completa.
* **Compartir:** Generación de enlaces y soporte para Códigos QR.
* **Gestión (Admin):** Panel para subir, editar y administrar los proyectos.
